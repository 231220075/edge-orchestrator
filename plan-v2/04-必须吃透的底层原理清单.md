# Edge-Orchestrator 二次重构 · 必须吃透的底层原理清单

> 直接对齐记忆库 knowledge_gap 里 Shopee 二面打穿你的 4 个点。每条都要练成「原理 + 选型 + 边界」三层口述，否则这次重构白做。

| 主题 | 必须能脱口而出的要点（三层） | 对应盲区 |
|---|---|---|
| Wasm 隔离原理 | 线性内存无裸指针逃逸、import 白名单、StoreLimits、epoch interruption | 🔴 沙箱虚拟 runtime 原理 |
| Container 隔离原理 | namespace 六类 + cgroup v2 三限额、二者边界「隔离 vs 限制」 | 🔴 同左 |
| tokio 原理 | executor + reactor + waker + work-stealing；RawNode 在单 tokio runtime 里怎么被 tick 驱动 | 🔴 tokio 原理 |
| Raft 一致性 | Pre-Vote 防脑裂、CheckQuorum、joint consensus、成员变更的 stub 口径 | 🔴 分布式一致性与选型 |
| libp2p 选型 | 为什么 mDNS（局域网可发现）/Noise（加密握手）/Yamux（多路复用）三者各司其职；无 gossipsub 的真实原因 | 🔴 选型完整性 |
| 内容寻址 CAS | SHA-256 + Git 对象模型 + packfile；「日志/代码/结果同 CAS」的去重价值 | 🟡 复用资产 |
