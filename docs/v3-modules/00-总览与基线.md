## 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| M1 砍骨 | 8→5 crate，build/clippy/fmt/test 全绿 |
| M2 沙箱真限额 | Wasm 死循环被 epoch 中断；OOM 被 StoreLimits 掐住 |
| M3 真分布式 | 3 节点 Raft 走 libp2p；kill leader 重选主；任务重路由 |
| M4 自然语言闭环 | 一句话 → 提交 → 路由 → 沙箱执行 → 结果回读 |
| M5 iPhone 触发（可裁剪） | HTTP+JSON-RPC 端点触发任务 |

## 开发铁律

1. 每个模块必须有单元测试，验收后才能进入下一个模块；
2. 跨模块集成测试贯穿始终，凡是"打通"必须有测试证据；
3. 不挖坑：不留语义为空的 stub（诚实标注处除外，且注明演进方案）；
4. 每模块完成即写文档（框架、选型、难题与解法）；
5. 遇到问题暂停并询问。
